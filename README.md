# Concrete Crack Detection Using CNN

## 1. Project Overview
This project focuses on detecting cracks in concrete surfaces using a Convolutional Neural Network (CNN).

## 2. Dataset
The dataset contains 40,000 concrete images.

- Training: 28,000 images
- Validation: 6,000 images
- Testing: 6,000 images
- Image size: 128 × 128 pixels
- Classes: Positive (Crack) and Negative (No Crack)

## 3. Technology Used
- Python
- TensorFlow and Keras
- Google Colab
- NVIDIA Tesla T4 GPU
- Convolutional Neural Network (CNN)

## 4. Model Training
The CNN model was trained for 3 epochs using the Adam optimizer and Binary Crossentropy loss function.

## 5. Evaluation
The model was evaluated using a separate test dataset. Test accuracy, confusion matrix, classification report, and sample predictions are available in the project notebook.

## 6. Example Images
This repository includes six sample concrete images showing cracked and non-cracked surfaces.

## 7. Limitations
The model was trained on a specific dataset. Its performance on real construction sites and different concrete surface conditions requires further testing.

## 8. Project Files
- `Week_6_Concrete_Crack_Detection.ipynb` — Complete training and evaluation notebook.
- `example_images/` — Sample concrete images.
